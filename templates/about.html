About CampusConnect Lost & Found

A high-efficiency, privacy-preserving, and secure collegiate lost-and-found system engineered specifically for university campuses and student unions.

🛡️

Safe Contact System

Traditional notice boards force students to post private phone numbers and personal emails publicly, leading to spam, stalking, and unwanted contact.

CampusConnect protects privacy: inquirers submit messages through an encrypted local inbox stored directly in SQLite. Only the verified poster can unlock and view them.

🔐

PIN-Based Authorization

No complex or expensive OAuth subscriptions needed! When posting an item, the user creates a personal 4-to-8 digit PIN.

The PIN is securely hashed using PBKDF2/SHA256 (via werkzeug.security). Anonymous public users cannot tamper with, edit, or maliciously resolve other students' items.

💻

100% Free Local Stack

Built strictly with free, standard software:

  • Backend: Python Flask
  • Database: Built-in SQLite (sqlite3) with parameterized SQL queries
  • Frontend: Semantic HTML5, Jinja2, custom responsive CSS, and vanilla JS
  • Cost: $0.00 — Zero paid subscriptions or proprietary cloud APIs

Judge & Evaluator Quick-Start Guide

1

Explore Demo Records & Interactive Rail

CampusConnect pre-seeds realistic records across popular campus spots (Library, Science Hall, Rec Center, Bus Stop). Each sample record is clearly badged with DEMO DATA.

2

Try the Demo Security PIN (1234)

All demo records use the PIN 1234. You can test resolving an open item, reopening a resolved item, or unlocking the private inquiry inbox on any demo card.

3

Test Submitting a New Item

Click Report Item to test the submission form. Form validation protects against missing fields, short descriptions, and invalid PINs.

4

Submit a Safe Inquiry

Open any item detail page and send a contact message. Verify that your message is safely stored in the database and visible only after entering the item PIN.
